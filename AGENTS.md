# AGENTS.md

This file provides guidance to Codex and other coding agents when working with code in this repository.

## Agent skills

### Issue tracker

Issues are tracked in this repo's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses the default triage label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This repo is configured as single-context. See `docs/agents/domain.md`.

### MCP
Use `code-review-graph` mcp to explore codebase first before use grep, find .etc

Use logs in logs/ folder to debug about scoring, parsing PDF, chatting

If you work with latex files or folders, compile it after finishing working.
