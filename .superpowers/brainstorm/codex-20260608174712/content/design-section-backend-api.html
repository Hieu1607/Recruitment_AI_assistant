Design section 2: Backend/API cho shortlist dispatch

Them lop workflow nho quanh shortlist, dung lai OutreachMessage va InterviewInvitation hien co.

Proposed API boundary
GET /shortlist/collections/{id}/dispatch-summary
Returns collection, candidate snapshot, latest outreach status, latest interview status, eligibility blockers.
POST /shortlist/collections/{id}/outreach-drafts
Creates missing drafts for selected candidates. Skips existing draft/sent messages unless force_update is true.
POST /shortlist/collections/{id}/interview-invitations
Creates queued interview invitations for selected candidates using an active template, with per-candidate result.

Dispatch summary response

{
  collection: { id, name, item_count },
  job: { id, title },
  candidates: [
    {
      candidate_profile_id,
      full_name,
      email,
      contact_status: "ready" | "missing_email",
      outreach: { latest_message_id, status, created_at, sent_at },
      interview: { latest_invitation_id, status, template_name, sent_at, completed_at },
      blockers: ["missing_email", "gmail_not_connected", "no_active_template"]
    }
  ],
  capabilities: { gmail_connected, active_interview_templates_count }
}

Batch command behavior

Moi batch endpoint tra ve result tung candidate: created, skipped_duplicate, skipped_missing_email, skipped_no_template, failed. UI dung ket qua nay de update row va hien success summary.

Why this shape

Noi dung batch can audit duoc va co duplicate detection vi workflow tuyen dung de gay nham lan khi communication bi tach khoi pipeline. Summary endpoint giu UI nhanh va tranh N+1 candidate calls.
