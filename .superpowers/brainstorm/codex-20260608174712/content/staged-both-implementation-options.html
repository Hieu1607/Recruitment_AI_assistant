3 cach trien khai "Both, staged"

Ca outreach va interview deu co trong shortlist, nhung muc do backend/state khac nhau. Chon cach phu hop voi toc do va do ben san pham.

A

URL handoff + existing endpoints

Shortlist them checkbox va 2 CTA. Outreach/Interview nhan query params candidate ids, collection id. It backend nhat, nhanh nhat.

Pros

  • Nhanh lam
  • Tan dung endpoint hien co

Cons

  • Kho batch status tot
  • De gui trung neu nhieu nguoi thao tac
B

Shortlist action summary endpoints

Them backend endpoint tra ve candidate snapshot + outreach latest status + interview latest status. Batch action tao drafts/invitations co preview va ket qua tung ung vien.

Pros

  • UX ro rang
  • Tranh duplicate
  • Hop kien truc hien co

Cons

  • Can them API va tests
C

Dedicated pipeline stage model

Them bang candidate pipeline/stage history: shortlisted, outreach drafted, outreach sent, interview invited, completed. Manh nhat cho analytics.

Pros

  • Ben cho dai han
  • Analytics tot

Cons

  • Scope lon
  • De cham MVP

Khuyen nghi

Chon B: them summary endpoint va batch endpoints nho. Day la diem can bang tot nhat giua toc do MVP va workflow thuc te: recruiter thay ai da co draft, ai da duoc moi interview, ai bi block vi thieu email/template/Gmail.
