# Plan 02-02: DataTable + Pagination

**Wave:** 1 (parallel with 02-01)

**Files modified:**

## Objective
Build a generic DataTable with sortable columns, sticky header, bulk-select checkboxes, skeleton loading, empty state slot, and a Pagination footer.

## Tasks

### Task 1: Pagination component
Create `src/components/ui/pagination.tsx` with:
- Props: `total`, `page`, `pageSize`, `onPageChange`, `onPageSizeChange`
- Display: "Showing X–Y of Z" in `font-sans text-sm text-fg-muted`
- Prev/Next buttons (32px square, ghost style, disabled at bounds)
- Page-size selector: 50/100/200 options via native `<select>` styled with hairline border

### Task 2: DataTable component
Create `src/components/ui/data-table.tsx` with:
- Generic `<DataTable<T>>` accepting `columns` definition + `data` array
- Column definition: `{ key, header, render?, sortable?, width? }`
- Sticky header: `position: sticky; top: 0; z-index: 10; bg-bg`
- Row hover: `hover:bg-[color:var(--hairline)]` transition
- Bulk-select: leading checkbox column, header checkbox (indeterminate) selects all on page
- Sort: clicking sortable header toggles asc/desc, shows `▲▼` icons
- Loading state: renders 8 `<SkeletonRow>` rows (use Skeleton from 02-04, but define inline shimmer for now)
- Empty state: slot prop `emptyState` renders when `data.length === 0`
- `onSelectionChange` callback with selected row IDs
