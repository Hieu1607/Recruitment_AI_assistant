## Objective
Create an internal `/dev/primitives` demo route that showcases every variant of every primitive, serves as living documentation, and proves all 5 Phase 2 success criteria.

## Tasks

### Task 1: Primitives showcase page
Create `src/routes/dev/primitives.tsx` with sections:
1. **Buttons** — all 5 variants × 3 sizes + loading state + icon-only
2. **Status Badges** — all statuses (pending, processing, completed, failed, sent, not_sent) in both sizes
3. **Avatars** — sm/md/lg/xl with initials + photo placeholder (via picsum.photos)
4. **Filter Chips** — single-select group of 5 chips with local toggle state
5. **DataTable** — 50 fake rows (generated), sortable name + score columns, bulk-select, empty state toggle
6. **Modal** — "Open Modal" button triggers a sample modal with header/body/footer
7. **Tooltip** — wraps text labels showing tooltip on hover
8. **EmptyState** — two examples: with action CTA and without
9. **Skeleton** — text, title, avatar, table-row, card variants
10. **Pagination** — interactive with local state (page/pageSize)
11. **ScoreVisualization** — mini bar (score=72), donut (score=85 with segments), radar (6 criteria)

Layout: single-column sections separated by `<hr className="hairline" />`, section titles in `font-display text-2xl`, 48px top padding.

### Task 2: Wire route
Add to `router.tsx` under authenticated routes:
```
{ path: "/dev/primitives", ...lazy(() => import("@/routes/dev/primitives")) }
```
