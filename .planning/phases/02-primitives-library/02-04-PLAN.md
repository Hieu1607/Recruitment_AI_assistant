## Objective
Build EmptyState (editorial heading + SVG + CTA), Skeleton (shimmer for rows/cards/text), and ScoreVisualization (mini bar, donut, radar — powered by Recharts).

## Tasks

### Task 1: Install Recharts
Add `recharts` to `frontend/package.json` dependencies.

### Task 2: Skeleton component
Create `src/components/ui/skeleton.tsx`:
- Base `<Skeleton>` with width/height props + className override
- Shimmer: CSS `@keyframes shimmer` — linear-gradient sweep from left to right over 1.5s
- Variants via className: `text` (h-4 w-3/4), `title` (h-6 w-1/2), `avatar-sm` (h-6 w-6 rounded-full), `avatar-md` (h-8 w-8 rounded-full), `table-row` (h-12 w-full), `card` (h-48 w-full rounded-md)
- Color: from `--hairline` to `--hairline-strong` gradient sweep
- `<SkeletonText lines={N}>` helper: renders N staggered text skeleton rows

### Task 3: EmptyState component
Create `src/components/ui/empty-state.tsx`:
- Props: `icon?` (ReactNode), `heading` (string), `body?` (string), `action?` (`{ label, onClick }`)
- Layout: centered column, gap-4, max-w-sm mx-auto py-16
- Heading: `font-display text-xl font-medium text-fg`
- Body: `font-sans text-sm text-fg-muted`
- Icon: 40px container, muted color, default to a generic inbox SVG
- Action: primary Button (sm) if provided
- Default illustration: minimal SVG inbox/folder icon (inline SVG, no external file)

### Task 4: ScoreVisualization component
Create `src/components/ui/score-visualization.tsx`:

**MiniBar** (`variant="bar"`):
- Props: `score` (0–100), `size?: "sm|md"`, `showLabel?: boolean`
- 80px wide track (h-1), filled segment in `--accent`, track in `--hairline`
- Optional percentage label right-aligned in `font-mono text-xs`

**ScoreDonut** (`variant="donut"`):
- Props: `score` (0–100), `segments?: {label, value, color}[]`
- Recharts `PieChart` with `Pie` (innerRadius=65, outerRadius=80 at 200px)
- Center text: score number in `font-mono font-bold text-2xl`
- Outer legend: segment labels in 11px sans below chart
- Container: 200px × 200px

**ScoreRadar** (`variant="radar"`):
- Props: `data: {subject, value, fullMark}[]`
- Recharts `RadarChart` 400×400
- `Radar` fill `rgba(31,58,46,0.18)` stroke `--accent` strokeWidth 2
- `PolarGrid` stroke `--hairline`, `PolarAngleAxis` tick font-sans 11px
- Container: 400px × 400px (responsive via ResponsiveContainer)
