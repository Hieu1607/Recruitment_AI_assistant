# Plan 02-03: Modal/Dialog + Tooltip

**Wave:** 2 (after deps install)
**Depends on:** @radix-ui packages installed
**Requirements:** PRIM-04, PRIM-09
**Files modified:**
- `frontend/src/components/ui/modal.tsx`
- `frontend/src/components/ui/tooltip.tsx`
- `frontend/package.json` (new deps: @radix-ui/react-dialog, @radix-ui/react-tooltip)

## Objective
Build accessible Modal (Radix Dialog) and Tooltip (Radix Tooltip) styled to the editorial design system.

## Tasks

### Task 1: Install Radix UI deps
Add to `frontend/package.json` dependencies:
- `@radix-ui/react-dialog`
- `@radix-ui/react-tooltip`

### Task 2: Modal/Dialog component
Create `src/components/ui/modal.tsx` wrapping `@radix-ui/react-dialog`:
- Exports: `Modal`, `ModalTrigger`, `ModalContent`, `ModalHeader`, `ModalFooter`, `ModalTitle`, `ModalDescription`
- Backdrop: fixed overlay with `rgba(0,0,0,0.4)` + `backdrop-blur-sm`
- Content: centered card, max-w-[560px] w-[calc(100%-2rem)], `--radius-lg` border-radius, `--shadow-lg`, bg-bg-elevated
- Header slot with serif title (Fraunces) + optional close X button
- Footer slot for action buttons
- Animation: enter with `opacity-0 scale-95` → `opacity-100 scale-100`, exit reverse — 200ms `--ease-out`
- Closes on Esc and backdrop click (Radix default behavior)
- `size: default | large` prop (560px vs 720px max-width)

### Task 3: Tooltip component
Create `src/components/ui/tooltip.tsx` wrapping `@radix-ui/react-tooltip`:
- Provider export: `TooltipProvider` (wrap at app root)
- Exports: `Tooltip`, `TooltipTrigger`, `TooltipContent`
- Content styling: bg-bg-elevated, `1px solid --hairline-strong`, `--shadow-md`, `--radius-sm`
- Font: 12px `font-sans`, `--fg`
- Max-w-[240px], padding 6px 10px
- Open delay: 400ms
- Arrow: small 6px arrow matching background
- Animation: fade-in 120ms ease-out
