## Objective
Build the four most-used atomic primitives: Button (5 variants × 3 sizes + loading + icon), StatusBadge (all 4 enum types), Avatar (photo + initial fallback), and FilterChip (single + multi-select).

## Tasks

### Task 1: Button component
Create `src/components/ui/button.tsx` with:
- Variants: `primary | secondary | ghost | danger | icon`
- Sizes: `sm | md | lg`
- Loading state: spinner replaces icon, label stays, pointer-events disabled
- Icon slot: leading icon via `icon` prop (ReactNode)
- Full focus ring: `outline-2 outline-accent outline-offset-2`
- Use `cn()` for class merging

### Task 2: StatusBadge component
Create `src/components/ui/badge.tsx` with:
- `variant` prop maps: `pending|queued` → neutral, `processing|running` → warning, `completed|active|passed|sent` → success, `failed` → danger, `not_sent|draft` → neutral
- Dot indicator + label layout
- `size: sm | md`
- Accept `UploadStatus | ProfileStatus | MatchRunStatus | SentStatus` string values

### Task 3: Avatar component
Create `src/components/ui/avatar.tsx` with:
- `src` prop for photo (img element)
- `name` prop for initial fallback — extract first + last initials
- Deterministic color per name (hash → pick from 6 accent shades)
- Sizes: `sm (24px) | md (32px) | lg (40px) | xl (56px)`

### Task 4: FilterChip component
Create `src/components/ui/filter-chip.tsx` with:
- `selected` boolean prop
- `onClick` handler
- Pill shape (`rounded-full`), hairline border → accent border when selected
- Optional leading icon slot

### Task 5: Barrel export
Create `src/components/ui/index.ts` that re-exports all UI components.
